Deskripsi Struktur:

1. File HTML Utama:
- index.html: Halaman beranda
- feed.html: Halaman feed sosial media
- events.html: Halaman event kopi
- order.html: Halaman pemesanan kopi

2. Folder assets/:
- Menyimpan semua aset statis
- Subfolder untuk gambar berdasarkan kategori

3. Folder css/:
- style.css: File CSS utama
- components/: CSS untuk komponen spesifik
- utils/: Utilitas CSS (variabel, animasi)

4. Folder js/:
- main.js: JavaScript utama
- components/: JS untuk komponen spesifik
- utils/: Fungsi utilitas dan helper

- Dokumentasi proyek
